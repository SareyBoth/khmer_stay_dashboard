# KhmerStay dashboard

A bilingual, responsive frontend demonstration for KhmerStay property owners and platform administrators. All records, preferences, messages, moderation decisions, financial displays, uploads, and verification flows remain in local browser state.

## Demo accounts

- Administrator: `admin@khmerstay.demo` / `Demo123!`
- Property owner: `owner@khmerstay.demo` / `Demo123!`

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000/login`.

## Verification

```bash
npm run lint
npm run typecheck
npm run test
npm run build
```

This prototype has no backend, API routes, database, Firebase, Supabase, PayWay, billing service, payment gateway, cloud upload, or live map integration.
